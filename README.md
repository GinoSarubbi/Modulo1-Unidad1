# Antes de React - Módulo 1 Unidad 1

Proyecto realizado para la consigna **Mi primera página web semántica y estilizada**.

## Descripción

Este proyecto consiste en una página web simple creada con **HTML semántico** y **CSS externo**. Incluye una estructura con `header`, `main`, `article`, formulario y `footer`, además de estilos aplicados mediante variables CSS.

## Estructura del proyecto

```text
Modulo1-Unidad1/
├── index.html
├── css/
│   └── styles.css
├── assets/
│   └── desarrollo-web.svg
└── README.md
```

## Cómo clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
cd Modulo1-Unidad1
```

## Cómo abrir la página

Abrir el archivo `index.html` directamente en un navegador web.

También se puede usar una extensión como **Live Server** en Visual Studio Code.

## Características incluidas

- Documento HTML válido con `<!DOCTYPE html>` y `lang="es"`.
- Estructura semántica con `header`, `main`, `article`, `section` y `footer`.
- Menú de navegación con lista `ul` y enlaces `a`.
- Artículo con `h2`, párrafo con `strong`, imagen con `alt` y lista ordenada `ol`.
- Formulario con campo de texto, email, selector y botón.
- CSS externo con variables declaradas en `:root`.
- Uso de selector de clase y selector de ID.
- Uso correcto de atributos `alt`, `for` y `name`.
- Sin estilos en línea.
